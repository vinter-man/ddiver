# Screenshots

The READMEs have no screenshots yet. They have to be taken by hand from a Telegram client —
nothing in this repository can produce them. This is the shot list.

## What to capture

Six shots, in this order. Save them here under exactly these names (PNG):

| File | What should be on screen |
|---|---|
| `01-notification.png` | A real notification: chat, sender, link, time, rule, the matched text with the keyword in bold, and both buttons underneath |
| `02-menu.png` | `/start` → the main menu |
| `03-chats.png` | The chat picker, with a couple of chats ticked (✅) and the rest unticked |
| `04-rules.png` | The rule prompt (`Rules → Add`), showing the syntax block |
| `05-status.png` | `/status` |
| `06-digest.png` | A digest, if you ever get one — otherwise skip it |

## Before you post them anywhere

- Crop to the message area; no need for the whole screen.
- Check every visible name, avatar and phone number. The chat titles and the people in them
  are real, and a screenshot in a public README is public forever.
- A test chat with your own two accounts makes the cleanest shots: you control both sides.
- Light or dark theme is fine, but use the same one for all of them.

## Wiring them in

Once the files are here, they are referenced from both READMEs as, for example:

```markdown
![A notification](docs/screenshots/01-notification.png)
```

Keep each file under ~300 KB so cloning the repository stays quick.
